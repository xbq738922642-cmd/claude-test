# 第4章　Amazonの日米におけるラストマイル配送体制（構成案と資料整理）

- 目的：RQ1「Amazonは日米において、どのような担い手、契約形態、管理方式によってラストマイル配送体制を構築してきたのか。また、それは時間とともにどのように変化してきたのか」に答える。
- 方針：事実の記述に徹し、理論的な分析は第5章で行う。日米を同じ観点（担い手／契約形態／管理方式／専用の投資／時期）で書き、4.4で一つの表にまとめる。
- 字数の目安：約8,000字（4.1 約2,800／4.2 約2,800／4.3 約1,000／4.4 約1,200＋表4-1）

## 4.1　米国の配送体制：DSPとAmazon Flex（約2,800字）

### 4.1.1　自社配送の開始（契機と初期の形態）
| 事実 | 出典 |
|---|---|
| 2013年のクリスマスシーズン、急増したAmazonの貨物にUPSが対応できず大規模な遅配。Amazonが自ら配送に乗り出す「最初の大きな契機」。顧客に20ドルのクレジットを支払う | 齊藤（2022，p.45） |
| 売上高に占める輸送コストの比率が2017年に12.2％に上昇 | 齊藤（2021，p.53） |
| 2014年、Amazon Freshの開始時に大都市で自前の配送を行う | 齊藤（2022，p.49） |
| 初期は配送業務を中小の運送業者に請負委託し、Amazonのロゴの入った専用車でAmazonブランドとして配送。ただし実態は明らかにされなかった | 齊藤（2021，p.55）；齊藤（2022，p.49） |
| 自社配送の比率：2016年末8％→2017年20％台→2018年30％台→2019年7月49％（Rakuten Intelligenceのデータ） | 齊藤（2022，p.46）；齊藤（2021，pp.53-54） |

### 4.1.2　DSP（2018年〜）
| 事実 | 出典 |
|---|---|
| 2018年開始。Amazonの貨物を専門に配送する運送会社を起業させるプログラム | 齊藤（2022，p.49）；齊藤（2021，p.56） |
| 規模：車両最大40台、従業員100人以下。必要な手元資金は1万ドル | 齊藤（2021，p.56） |
| Amazonのロゴ入り専用車、Amazonの制服。専用車両・制服・燃料・保険を割引価格で提供。配送経験がなくてもAmazonが指導 | 齊藤（2021，p.56） |
| 2018年9月にメルセデス・ベンツの配送用バンを2万台発注。車両管理会社が購入してDSPにリース | 齊藤（2021，p.56）；齊藤（2022，p.50） |
| 「小規模なフランチャイズ型」。FedExのやり方を参考にした | 齊藤（2022，p.50） |
| 規模の推移：2020年 米国で約800社・約7.5万人（Bank of America）／2020年9月 5か国で1,500社以上・10万人以上・年22億個（Amazon発表）／2021年8月 米国で約2,000社・約11.5万人（CNBC） | 齊藤（2022，pp.50-51）；齊藤（2021，p.57） |
| ドライバーはDSPに雇用される | 齊藤（2021，p.57） |

### 4.1.3　DSPに対する管理
| 事実 | 出典 |
|---|---|
| 独自のルーティング・アルゴリズムで配送ルートを割り当て、ルートごとの配送個数を決めて指示 | 齊藤（2022，p.51） |
| ビデオカメラ、テレマティクス、アプリで運転行動を監視（シートベルト、速度、ブレーキ、電話の使用など） | 齊藤（2022，pp.51-52） |
| 毎週のスコアカードに基づき、1個当たりの運賃が10〜25セントの範囲で変動 | 齊藤（2022，p.51） |
| ドライバーの評価（FICOスコア）がDSPの評価に影響。DSPを4段階で評価し、評価の低いDSPとは契約を解除（2020年10月に3,200人のドライバーがレイオフ） | 齊藤（2022，p.52） |
| 1日1ルート250個の配送が求められ、長時間労働・高い離職率 | 齊藤（2022，pp.52-53） |

### 4.1.4　Amazon Flex（2015年〜）
| 事実 | 出典 |
|---|---|
| 2015年開始。自家用車を保有する一般のドライバーが配送する、Uberと同じ仕組み | 齊藤（2021，p.55）；齊藤（2022，p.53） |
| 専用アプリで配送業務を遂行。時給18〜25ドルとされるが、経費を差し引くと5〜11ドルとの報告 | 齊藤（2021，p.55） |
| 投資会社Cowenの推計：2019年の自社配送の23％をFlexが担う → DSPが約4分の3（齊藤の単純計算）。実際の規模は明らかにされていない | 齊藤（2022，p.55） |

## 4.2　日本の配送体制：ADPとAmazon Flex（約2,800字）

### 4.2.1　自社配送の開始（契機）
| 事実 | 出典 |
|---|---|
| 2017年の宅配クライシスが脱宅配便の「重要な契機」。ヤマト運輸が当日配達の停止、総量規制、40％の運賃値上げ | 齊藤（2022，p.56） |
| 大手宅配便3社の利用率：2017年4月94％→2020年9月41％（「その他」59％）。資料：ウケトル調べ | 齊藤（2022，pp.56-57） |
| 2021年、出荷約7億個のうち約半数（約3億5,000万個）が宅配便以外 | 齊藤（2022，p.57）；齊藤（2023，pp.36-37） |

### 4.2.2　ADP（デリバリープロバイダ）
| 事実 | 出典 |
|---|---|
| 自社配送体制の整備は、特定地域にネットワークを持つ既存のトラック運送事業者を起用することから始まった ※林は「DSP」と表記 | 林（2023，p.10） |
| FCを大都市周辺に設置したことで、地域限定のローカルな運送業者への委託が可能になった | 齊藤（2022，pp.57-58） |
| 当初9社（丸和運輸機関、SBS即配サポート、札幌通運、ロジネットジャパン西日本、遠州トラック、ファイズ、若葉ネットワーク、ギオンデリバリーサービス、ヒップスタイル）。TMGは2020年10月に契約解除 | 齊藤（2022，p.58，表4.1）；齊藤（2023，p.37） |
| ADPは配送業者を組織化し、契約管理・稼働管理・支払い管理を行う。Amazonは自社のDSや配送アプリでADPを支援 | 林（2023，p.10） |
| Amazonへの売上高依存度（2021年）：ファイズHD 69.9％、遠州トラック34.4％、丸和運輸機関23.4％、ロジネットジャパン17.5％ | 齊藤（2022，pp.58-59，表4.2） |
| 丸和運輸機関のドライバー（2019年末、約2,000人）：協力会社約7割、個人の軽貨物運送事業者2.5割、正社員0.5割。個人を起業させてAmazonの配送に動員 | 齊藤（2022，pp.59-60） |
| 下請けの個人：原則9時〜21時の12時間、日当1万7,000円、月収約20万円 | 齊藤（2022，pp.60-61） |
| Amazonは大手宅配便事業者と同様に単純に委託。米国のような監視・コントロールは行っていない | 齊藤（2022，p.65） |
| ★ただし、ADPの下請けの軽貨物運送事業者には、Amazonから配達エリアと個数が割り振られ、ルートと貨物の割当てはAIで行われている。1日平均個数：2020年7月116個→2022年5月214個、報酬は日当1万8,000円で一定 | 齊藤（2023，pp.44-45） |

### 4.2.3　Amazon Flex（2018年〜）
| 事実 | 出典 |
|---|---|
| 2018年開始。黒ナンバーの貨物軽自動車を持つ個人事業主とAmazonが直接業務委託契約 | 林（2023，p.10）；長谷川（2023，p.45） |
| 米国は自家用車の個人、日本は軽貨物運送事業者。同じ名称でも内容が大きく異なる | 齊藤（2022，p.61） |
| 条件：20歳以上、スマートフォン、普通免許、自分名義の黒ナンバー車、任意保険 | 齊藤（2022，pp.61-62） |
| ブロック（4〜8時間）を選択。関東の例：1日2ブロックで2万370円 | 齊藤（2022，p.62）；長谷川（2023，p.46） |
| ADPの下請けからFlexへの転換、コロナ禍での失業者の参入。2021年2月に1万人突破（産経新聞） | 齊藤（2022，p.62） |
| Flexの費用はADPより安いが、Flexだけでは需要変動への対応が不十分。ADPは組織力に勝り安定的に供給 | 齊藤（2023，p.41） |
| （補足）2022年12月、Amazon Hub デリバリーパートナープログラム | 林（2023，p.11） |

## 4.3　日本DSPの導入（約1,000字）
| 事実 | 出典 |
|---|---|
| 2024年問題が近づき運転者不足が深刻化するなか、2023年3月に「より踏み込んだ」DSPプログラムを導入。経験のない人を含めて起業を支援、開業後は安定的に配送貨物量を供給 | 林（2023，p.10） |
| 保有台数20〜40台程度を想定。5台で開業資金約120万円。20〜40台で年間売上高1億4,900万〜2億9,800万円、利益1,210万〜2,470万円 | 齊藤（2023，p.39） |
| 支援：自動車保険・モバイルデータサービスの紹介、運営ツール・テクノロジーの有償提供、問題発生時の情報提供 | 齊藤（2023，p.39） |
| 米国と同じような仕組みを日本でも新たに導入 | 齊藤（2023，p.39） |
| 公式発表 | アマゾンジャパン（2023） |

## 4.4　小括（表4-1の案）
| 項目 | 米国DSP | 米国Flex | 日本ADP | 日本Flex | 日本DSP |
|---|---|---|---|---|---|
| 開始 | 2018年 | 2015年 | 2017年〜 | 2018年 | 2023年 |
| 担い手 | 新たに起業した小規模運送会社 | 自家用車の一般個人 | 既存の地域運送事業者（＋協力会社・個人の下請） | 届出をした個人事業主 | 新たに起業した運送会社 |
| 契約 | Amazon専属のフランチャイズ型委託 | Amazonと個人の直接委託 | Amazon→ADP→下請の多重構造 | Amazonと個人の直接委託 | Amazonとの委託（起業支援） |
| 専用の投資 | Amazonブランドの専用車（リース）、制服 | 自家用車（転用可能） | ADPはAmazon以外の事業もある（依存度2〜7割） | 黒ナンバー車（他の荷主にも転用可） | （情報が限られる） |
| 管理 | ルート・個数の割当て、監視、評価、運賃変動、契約解除 | アプリ | 単純な委託（ただし下請にAIで個数割当て） | アプリ・ブロック | （情報が限られる） |

## 注意点
1. 林（2023）は既存の地域運送事業者（＝ADP）を「デリバリーサービスパートナー（DSP）」と表記している。注で説明する。
2. 齊藤（2022，p.65）「監視・コントロールは行っていない」と、齊藤（2023，pp.44-45）「Amazonから個数が割り振られAIで割当て」は一見食い違う。時点（2023年の論文は2022年までのデータ）と対象（ADP本体か下請ドライバーか）の違いとして整理し、日本でも管理が強まりつつある可能性として第6章につなげる。
3. 規模・比率は推計（Cowen、Rakuten Intelligence、ウケトル）や報道にもとづく。「〜とされる」「推計によれば」と書く。
4. 4.1・4.2は時系列で書き、RQ1の「時間とともにどう変化したか」に答える。
